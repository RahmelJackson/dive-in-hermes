# Dive In hackathon demo

Open **Dive In** in Hermes Desktop and choose **Try the GPU story**. The sample
uses captured evidence and runs without a model. It preserves a historical
survey snapshot and the source links used in the original investigation.

| Time | Show and say |
| --- | --- |
| 0–6 s | **The question.** “Can an older gaming PC beat a Switch 2? This thread argues about three different things.” |
| 6–16 s | **The exchange.** Open the GPU story and follow the submitted post, quoted post, and reply. |
| 16–27 s | **The disagreement.** Move to perspectives and separate performance, ownership, and cost. |
| 27–42 s | **The fact-check.** Select the RTX 5090 bar. The reply says 1% and the saved Steam survey shows 0.43%. |
| 42–54 s | **The source map.** Open Big Picture, select Sources, and show how each layer leads back to the evidence. |
| 54–66 s | **The next question.** Open the performance comparison, then ask whether a directly comparable test exists. |
| 66–73 s | **Hermes Desktop.** Show where Dive In opens from the sidebar. |

## Alternate offline evidence-ledger demo

| Time | Show and say |
| --- | --- |
| 0–15 s | Run the offline demo command from the README or ask Hermes Desktop to load the synthetic fixtures. “Signal Atlas puts public feeds about one topic into a single evidence ledger.” |
| 15–30 s | Open `signals`. “Three distinct articles appeared in the latest seven-day window versus one in the previous window. The pilot link appears in two feeds and counts once.” |
| 30–46 s | Open `narrative` and expand the shared pilot URL relationship. “The city reported cooler roof surfaces. These two IDs preserve the original feed observations. The result leaves indoor temperature open.” |
| 46–61 s | Open `conversation`. “A renter asks whether top-floor apartments will cool overnight. A researcher calls for indoor readings. Each candidate links to the excerpt that surfaced it.” |
| 61–75 s | Open `context` and inspect the maintenance question's evidence ID. “This feed gave a timestamp without a timezone. The raw date is preserved, and this item stays out of the signal count.” |
| 75–90 s | Open `brief`. “The reporting opportunity is a renter Q&A about indoor heat and coating costs. Start with these cited questions, then request indoor temperature data and the maintenance budget.” |
